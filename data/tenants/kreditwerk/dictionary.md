# Kreditwerk Export

Ein Datensatz je Firmenkunde, Beteiligte unter `beteiligte`.

| Feld | Bedeutung |
|---|---|
| kunden_nr | Prüfnummer |
| firma | Firmenname |
| handelsregister | HRB-Nummer |
| sitz | Sitz |
| land | Land (ISO alpha-2) |
| beteiligte[].rolle | Geschäftsführer oder wirtschaftlich Berechtigter |
| beteiligte[].vorname, nachname | Name |
| beteiligte[].geburtsdatum | TT.MM.JJJJ |
| beteiligte[].geburtsort | Geburtsort |
| beteiligte[].staatsangehoerigkeit | Adjektiv, z. B. deutsch, türkisch |
