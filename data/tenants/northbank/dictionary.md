# Northbank export

One record per private customer, from the core banking system.

| field | meaning |
|---|---|
| ref | screening id |
| name | SURNAME/GIVEN, upper case |
| dob | YYYYMMDD |
| cob | country of birth, English name |
| pob | city of birth |
| nat | nationality, ISO 3166-1 alpha-3 |
| addr | city of residence |
