# Finvia export

One JSON object per screened customer (private individuals).

| field | meaning |
|---|---|
| customer_id | screening id |
| first_name, last_name | as on the ID |
| birth_date | ISO 8601, YYYY-MM-DD |
| nationality | ISO 3166-1 alpha-2 |
| birth_place | city of birth |
| residence | city, country |
| occupation | free text |
